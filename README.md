# Issue Scout

**Find open-source issues that fit your skills and interests.**

Issue Scout is an open-source project designed to help beginners
and experienced developers discover useful GitHub issues to work on.

## Features

- Keyword search against public GitHub issues.
- Label and programming-language filters.
- Heuristic skill-level suggestions, including unspecified difficulty.
- Direct links to original issues.
- Loading and error handling.
## Roadmap

- More accurate language-based discovery.
- Saved issues and personal preferences.
- Optional AI-assisted summaries in a later version.

Skill levels are estimates, not guarantees. Issue Scout links
to GitHub for the authoritative issue details.

## Tech stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- GitHub REST API

## Development status

Early development. The features listed above are planned and
will be implemented incrementally.

## Run locally

Requirements: Node.js 20.9 or newer.

1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.
