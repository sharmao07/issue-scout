# Issue Scout

> pls star hehe i'll improve it a lot in upcoming days, im just busy cus of exams and maybe we can work together on it so star plspls

i wanted to contribute to open source projects but i had no idead where or how to start from, I researched a little about github api and made issue scout. Beginners like me or even intermediates can easily use issue scout and narrow down search results using filters provided

## website

[issue scout](https://issue-scout-chi.vercel.app/)

## some features

- search using tons of available filters (adding more soon)
- 8 points checklist to solve the issues
- bookmark issues which are saved locally in browser
- no need for accout or login

Difficulty and readiness scores are estimates, not guarantees. Always check the original issue before contributing.

## Run it locally

Requires Node.js 20 or newer.

```bash
git clone https://github.com/sharmao07/issue-scout.git
cd issue-scout
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).
