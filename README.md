# Issue Scout

Discover open source issues to contribute to

## Introduction

- **How it works:** Issue scout uses next.js to call the rest api of GitHub, and then provide them to a responsive react interface.

- **Filters:**Provides choice for tons of filter to narrow down open source issues. Some are languages, keywords, labels, dates and more.

- **Free and open source to use** under MIT License.

- **Private:**Everything is saved locally in your browser, no need for login.

- **Skill level**Estimates skill levels for issues and readiness scores.


> **Note**: Estimated skill levels and readiness scores are suggestions generated automatically based on issue labels and other repository information.


## Contribute

Bug reports, ideas, and pull requests are welcome. Start with [CONTRIBUTING.md](CONTRIBUTING.md).

**Set up locally:**

Needs node.js 20 or later

```bash
git clone https://github.com/sharmao07/issue-scout.git
cd issue-scout
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
